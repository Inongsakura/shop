# INONGSHOP

เปิด `index.html` ด้วย Chrome/Edge และเชื่อมต่ออินเทอร์เน็ต ไม่ต้องเปิดเซิร์ฟเวอร์

## ไฟล์หลัก

- `index.html` — หน้าเว็บ ทุกเมนูเปิดจากหน้านี้
- `assets/` — รูปสำรอง CSS และ JavaScript ที่เว็บใช้งาน ห้ามนำออก
- `firebase.json` และ `firestore.rules` — การตั้งค่าและสิทธิ์ฐานข้อมูล
- `development/` — ต้นฉบับและเครื่องมือสำหรับแก้ไข/ทดสอบ ไม่ต้องเปิดเมื่อใช้งานเว็บ

ระบบชำระเงินและคีย์เป็นการสาธิต ไม่มีการรับเงินจริง ผู้ดูแลคือ rust2tf2@gmail.com ใช้รหัสผ่านสมาชิก Firebase ของตนเอง

## ชำระเงินจำลอง

สมาชิก: สร้างคำสั่งซื้อ → ไปชำระเงินจำลอง → เลือกโอนหรือสแกน → แนบภาพสลิปจำลอง PNG/JPEG ไม่เกิน 200 KB (เว้นว่างเพื่อสร้างหลักฐาน DEMO) → รอแอดมินตรวจ → รับคีย์ที่เมนูคลังเกม

ผู้ดูแล: หลังบ้าน → คำสั่งซื้อ / ตรวจชำระ → ดูหลักฐาน → อนุมัติและส่งคีย์ หรือไม่อนุมัติ / ยกเลิก ยอดทั้งหมดเป็นยอดสมมติ ใบเสร็จไม่ใช่เอกสารทางการเงิน

แก้ชื่อธนาคาร ผู้รับ คำแนะนำ และเปิด/ปิดช่องทางได้ที่ หลังบ้าน → ตั้งค่าชำระเงิน รหัสบัญชีรับเฉพาะ DEMO- ตามด้วยตัวอักษรอังกฤษ ไม่ใช้เลขจริง QR เป็นภาพสาธิตที่สแกนโอนไม่ได้ ไม่มีบัตรหรือการตรวจสลิปธนาคารจริง ห้ามแนบสลิปจริง รูปหลักฐานเก็บกับคำสั่งซื้อใน Firebase โดยเจ้าของและแอดมินเท่านั้นที่อ่านได้

## แก้ไขและทดสอบ

เปิดโฟลเดอร์ `development` แล้วรัน `npm ci` ตามด้วย `npm run build` เพื่อสร้างไฟล์เว็บกลับไปยัง index.html และ assets ที่โฟลเดอร์หลัก ใช้ `npm run test:ui` ทดสอบส่วนหน้า ส่วนการทดสอบฐานข้อมูลต้องมี Java 21+ และ Firebase CLI แล้วรันจาก development: `firebase emulators:exec --config ../firebase.json --project demo-inong-static --only auth,firestore "npm test"` ห้ามทดสอบด้วย project จริง

ต้นฉบับหน้าตาอยู่ใน development/src/page.html, storefront.js, restored.css และ ui.js ส่วนการเชื่อมข้อมูลอยู่ใน development/firebase-adapter.js
