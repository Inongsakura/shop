# ผลทดสอบรุ่น Local + Firebase — 8 กันยายน 2026

## หน้าโปรไฟล์ / หลังบ้าน / การชำระเงินจำลอง — 9 กันยายน 2026

- ส่วนหน้า 5/5: หน้าร้านและรูปเดิม, ตัวกรอง, ป้องกันข้อความแทรก HTML, หน้าชำระมีเฉพาะโอน/QR, ต้องยอมรับการจำลอง, ปฏิเสธชนิด/ขนาดไฟล์ไม่ถูกต้อง
- Firebase Emulator 8/8: สิทธิ์สมาชิก/แอดมิน, สร้างคำสั่งซื้อไม่ซ้ำ, ห้ามสมาชิกอนุมัติเอง/แก้ยอด/แก้หลักฐานหลังส่ง, ส่งคีย์ครั้งเดียว, ระงับสมาชิก, ปฏิเสธยอดปลอม, แข่งขันซื้อคีย์สุดท้าย, ตั้งค่าช่องทางเฉพาะแอดมินและไม่รับเลขบัญชีจริง
- ชุดสคริปต์ Firebase เริ่มต้นได้ ฐานข้อมูลชื่อ default และไฟล์เว็บตรวจไวยากรณ์/ค่าแฮชผ่าน
- รวมตั้งค่า Emulator ไว้ใน firebase.json ที่ราก ไม่ต้องมี firebase.emulators.json ซ้ำ
- ไม่ได้ทดสอบการเปิด file:// และคลิกครบทุกหน้าในเบราว์เซอร์จริง ผลส่วนหน้าเป็นการทดสอบโค้ด/HTML ที่สร้าง ไม่ใช่การยืนยันภาพทุกขนาดหน้าจอ
- ไม่รับเงินจริง ไม่มีบัตร ไม่มีการตรวจสลิปธนาคารจริง QR จงใจเป็นภาพสาธิตที่จ่ายไม่ได้


## คืนหน้าตาเดิม — 9 กันยายน 2026

- คืนแบนเนอร์ภาพ 3 สไลด์ เมนูเดิม การ์ดเกม ส่วนเกมแนะนำ/ลดราคา/มาใหม่ หมวดหมู่ และท้ายเว็บโทนม่วง
- คืนรูปปกเกมจริง พร้อมรูปสำรองเมื่อเครือข่ายหรือรูปต้นทางมีปัญหา
- แยกหน้า HTML, ไฟล์ CSS และสคริปต์ธรรมดาใน assets เพื่อเปิดจากไฟล์ได้ ไม่ต้องใช้เซิร์ฟเวอร์
- ค้นหา แพลตฟอร์ม ประเภท ช่วงราคา และลิงก์โปรโมชั่นส่งตัวกรองถึงร้านค้าได้
- เข้าสู่ระบบ/สมัครสมาชิกสลับแท็บได้ และเพิ่มช่องแก้ URL รูปปกในหลังบ้าน
- ทดสอบตรรกะส่วนหน้า 4/4 ผ่าน และระบบ Firebase จำลอง 7/7 ผ่าน
- ตรวจไวยากรณ์ไฟล์ที่สร้างจริงและ Firebase bundle เริ่มทำงานได้ผ่าน
- ยังไม่สามารถตรวจภาพหน้าจอหรือดับเบิลคลิก file:// ด้วยเครื่องมือเบราว์เซอร์ในงานนี้ได้ จึงไม่รับรองความเหมือนระดับพิกเซล

บันทึกด้านล่างเป็นประวัติรุ่นก่อนหน้าที่รวมทุกอย่างไว้ใน HTML เดียว ซึ่งรุ่นใหม่แทนที่ด้วย assets แล้ว

แก้ไขเพิ่มเติม: พบและทำซ้ำข้อผิดพลาด `app/no-app` ใน Firebase SDK ที่รวมไว้ได้ สาเหตุคือการผสม import/require ทำให้มี Firebase app registry สองชุด แก้ให้ส่ง SDK ชุดเดียวเข้า database adapter แล้ว ทดสอบเริ่มแอปและฐานข้อมูลจาก bundle จริงผ่านด้วย `check-sdk.cjs` และเพิ่มการตรวจนี้ใน `npm run build`

- Firebase SDK 12.18.0 และกฎ Firestore: ทดสอบผ่าน 7/7 กรณีบน Emulator
- สมัครสมาชิก/ข้อมูลส่วนตัว/รายการโปรด/คำสั่งซื้อซ้ำแล้วได้รายการเดิม
- สมาชิกอ่านข้อมูลคนอื่น อ่านคีย์ที่ยังไม่ขาย หรือกำหนดตัวเองเป็นแอดมินไม่ได้
- สมาชิกยืนยันว่าชำระเสร็จเองหรือแก้ยอดหลังสร้างคำสั่งซื้อไม่ได้
- ผู้ดูแลอนุมัติและส่งคีย์ได้ครั้งเดียว สต็อกถูกตัดตรงจำนวน
- รีวิวได้เฉพาะเกมที่ได้รับคีย์แล้ว บัญชีถูกระงับทำรายการไม่ได้
